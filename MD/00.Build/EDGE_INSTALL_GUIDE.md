# 선박 인트라(로컬) PMS 설치 가이드 — 현장용

> 이 문서는 **선박에 로컬 PMS 서버를 설치**하는 방법을 순서대로 설명합니다.
> 컴퓨터에 익숙하지 않아도 **위에서부터 그대로 따라 하면** 됩니다.
> 막히면 맨 아래 **"문제가 생기면"** 을 보세요.
>
> ⚠ **이 문서는 빈 PC에 처음 설치하는 경우**입니다. 선박에 document 프로그램 DB가 이미 있으면
> [SHIP_SYNC_INSTALL_GUIDE.md](SHIP_SYNC_INSTALL_GUIDE.md) 를 따르세요(`1B_기존DB에_PMS테이블_추가.bat` 사용, 10분 자동 동기화·수동 동기화 버튼 설명 포함).

---

## 0. 시작하기 전에 — 준비물 체크 ✅

| 준비물 | 설명 |
|--------|------|
| ☐ 선박 서버 PC | 선내에 둘 컴퓨터 (항상 켜둠). 선내 LAN에 연결돼 있어야 함 |
| ☐ 설치 패키지 | 본사에서 받은 폴더 (프로그램 + 설치 스크립트) — 예: `USB\ToadsPMS-Edge\` |
| ☐ **설정값 시트** | 본사에서 받은 종이/파일. 아래 4가지가 적혀 있음 ↓ |

### 본사에서 받는 "설정값 시트" (이 4개가 꼭 필요)

| 항목 | 예시 | 뜻 |
|------|------|-----|
| ① 선박 코드 | `DSRJ2` | 이 배의 고유 코드 |
| ② 중앙 서버 | `pms` 또는 `ycpms` | 우리 회사(toads=pms / 영창=ycpms) |
| ③ 노드 토큰 | `a1b2c3...` (긴 문자열) | 이 배 전용 인증 열쇠 |
| ④ DB 비밀번호 | (본사 지정) | 아래 3단계에서 정할 값 |

> 이 4개가 없으면 설치를 진행할 수 없습니다. 먼저 본사에 요청하세요.

---

## 1. PostgreSQL(데이터베이스) 설치

선박 데이터를 저장할 프로그램입니다. 한 번만 설치하면 됩니다.

1. 설치 패키지의 `postgresql-설치파일.exe` 실행
2. **다음 → 다음** 으로 진행 (기본값 그대로)
3. 중간에 **비밀번호를 정하라**고 나오면 → **설정값 시트 ④ DB 비밀번호**를 입력
   - ⚠️ 이 비밀번호를 꼭 기억/기록하세요. 뒤에서 또 씁니다.
4. 포트는 **`5432`** 그대로 두기
5. 설치 완료

---

## 2. 데이터베이스 만들기 (자동 스크립트)

설치 패키지 안의 스크립트를 한 번 실행하면 자동으로 준비됩니다.

1. 설치 패키지 폴더에서 **`1_데이터베이스_준비.bat`** 더블클릭
2. 비밀번호를 물으면 → **③ 1단계에서 정한 DB 비밀번호** 입력
3. 화면에 **`완료 (준비됨)`** 이 나오면 성공

> 이 스크립트는 빈 데이터베이스와 표(테이블) 구조만 만듭니다. **실제 배 데이터는 다음 단계에서 중앙 서버가 자동으로 채워줍니다.**

---

## 3. 설정 파일 작성 (제일 중요 — 4곳만 채우기)

설치 패키지 폴더의 **`config.env`** 파일을 **메모장으로 열어서**, 아래 4곳만 채웁니다.
(나머지 줄은 건드리지 마세요.)

```ini
# ① 선박 코드  (설정값 시트 ①)
VESSEL=DSRJ2

# ② 중앙 서버  (pms 이면 아래 그대로 / ycpms 이면 pms → ycpms 로만 변경)
REMOTE_SITE_URL=https://pms.toads.kr

# ③ 노드 토큰  (설정값 시트 ③ — 긴 문자열 그대로 붙여넣기)
NODE_TOKEN=여기에_토큰_붙여넣기

# ④ DB 비밀번호  (1단계에서 정한 값)
DB_PASS=여기에_비밀번호

# ── 접속 포트 (그대로 두기, 바꿀 일 있으면 본사 문의) ──
PORT=30001
```

**작성 예시** (toads 소속, 선박 DSRJ2):
```ini
VESSEL=DSRJ2
REMOTE_SITE_URL=https://pms.toads.kr
NODE_TOKEN=（본사에서_받은_긴_문자열）
DB_PASS=배에서정한비밀번호
PORT=30001
```

> 💡 영창 소속이면 ②만 `https://ycpms.toads.kr` 로 바꾸면 됩니다.

저장하고 닫습니다.

---

## 4. 서버 켜기

1. 설치 패키지 폴더에서 **`2_서버_시작.bat`** 더블클릭
2. 검은 창이 뜨고 잠시 후 **`Ready`** 또는 **`서버 시작됨`** 이 보이면 켜진 것
3. ⚠️ **이 창을 닫지 마세요** (닫으면 서버가 꺼집니다). 최소화만 하세요.

> 인터넷이 연결돼 있으면, 서버는 **자동으로 중앙에서 이 배(선박 코드)의 데이터를 받아옵니다.**
> 처음 켤 때 데이터가 다 들어오기까지 **1~3분** 걸릴 수 있습니다. 잠시 기다리세요.

---

## 5. 접속 확인

### 서버 PC에서 확인
- 웹 브라우저(크롬)를 열고 주소창에 입력:
  **`http://localhost:30001`**
- 로그인 화면이 나오면 성공 ✅

### 다른 선내 PC/태블릿에서 접속
- 서버 PC의 **IP 주소**로 접속합니다. 예: **`http://192.168.10.5:30001`**
- (서버 PC의 IP는 본사가 알려주거나, 서버 PC에서 확인 가능)

### 로그인
- 승선원 계정(중앙에 등록된 아이디/비밀번호)으로 로그인
- **인터넷이 끊겨도** 로그인·사용이 됩니다 (데이터가 배 안에 저장돼 있으므로)

---

## 6. 평소 사용

- 서버 PC는 **항상 켜두고**, `2_서버_시작.bat` 창은 **열어둡니다**.
- 인터넷(위성/LTE)이 연결되면 서버가 **알아서** 중앙과 데이터를 주고받습니다.
- 인터넷이 끊긴 동안 입력한 정비·재고 기록은 **배 안에 저장**됐다가, 인터넷 복구 시 **자동으로 중앙에 전송**됩니다.
- 별도로 "동기화" 버튼을 누를 필요 없습니다.

---

## 문제가 생기면 🔧

| 증상 | 해결 |
|------|------|
| 브라우저에서 화면이 안 뜸 | `2_서버_시작.bat` 창이 켜져 있는지 확인. 꺼졌으면 다시 더블클릭 |
| "데이터베이스 연결 실패" | PostgreSQL이 켜져 있는지 확인. `config.env`의 **DB 비밀번호(④)**가 맞는지 확인 |
| 로그인은 되는데 배 데이터가 비어 있음 | 인터넷 연결 확인 → 1~3분 기다리기. 안 되면 **③ 노드 토큰**이 맞는지 본사 확인 |
| 서버 PC 재부팅 후 | `2_서버_시작.bat` 을 다시 더블클릭 (PostgreSQL은 자동 시작됨) |
| 그 외 | **본사 IT 담당**에게 연락 (아래 화면의 검은 창 내용을 사진 찍어 전달하면 빠름) |

---

## 요약 (한눈에)

```
1. PostgreSQL 설치 (비밀번호 정하기)
2. 1_데이터베이스_준비.bat 실행
3. config.env 에 4개 값 채우기 (선박코드·중앙서버·토큰·비밀번호)
4. 2_서버_시작.bat 실행 (창 열어두기)
5. http://localhost:30001 접속 → 로그인
   → 인터넷 연결 시 자동으로 데이터 수신·동기화
```

> 설정값 시트(선박코드·중앙서버·토큰)는 **본사에서** 미리 발급합니다.
> 현장에서는 **설치 → 값 4개 입력 → 켜기** 만 하면 됩니다.
